## 📖 Sobre o Projeto

O **Clima Amanhã** é uma plataforma digital desenvolvida como suporte visual e interativo para a apresentação acadêmica do curso de **Arquitetura e Urbanismo** da **Universidade Cruzeiro do Sul**.

O objetivo central é traduzir dados científicos e desafios climáticos complexos (como o avanço das ondas de calor extremo e a intensificação do Super El Niño) em uma experiência visualmente rica, sensível e acessível. A iniciativa conecta o diagnóstico dos desastres socioambientais a respostas concretas formuladas pelo urbanismo e pela **arquitetura bioclimática**, demonstrando o papel fundamental do planejamento espacial e dos pontos de apoio na mitigação de riscos e na proteção de populações vulneráveis.

---

## 🎯 Destaques & Objetivos

- **Conscientização & Impacto Social:** Abordar a crise climática não como um cenário distante, mas como uma emergência presente com reflexos na saúde pública, na mortalidade urbana e na desigualdade social.
- **Arquitetura Bioclimática na Prática:** Apresentar estratégias projetuais sustentáveis — ventilação cruzada, conforto térmico passivo, sombreamento natural, superfícies permeáveis e materiais de baixa inércia térmica.
- **Narrativa Editorial:** Estrutura inspirada no design editorial contemporâneo, revistas visuais e sites de storytelling, aliando tipografia expressiva e composições assimétricas.
- **Utilidade Pública:** Disponibilização de canais de socorro, emergência e defesa civil para apoio imediato à população em momentos críticos.

### 1. 🌡️ Os Perigos do Calor Extremo
- Análise de como o calor severo sobrecarrega os sistemas cardiovascular e respiratório.
- Estatísticas sobre o aumento da taxa de mortalidade a cada +1 °C na América Latina.
- A intensificação do efeito **Ilha de Calor Urbana** decorrente da impermeabilização do solo, escassez de vegetação e retenção térmica do concreto e asfalto.

### 2. 🌊 O Fenômeno El Niño & Super El Niño
- Esquemas interativos e didáticos sobre o aquecimento anômalo das águas do Oceano Pacífico Equatorial e a alteração dos ventos alísios.
- Mapeamento das consequências no território brasileiro: secas severas no Norte/Nordeste e precipitações volumosas no Sul.
- Análise de como o aquecimento global potencializa eventos meteorológicos extremos.

### 3. 🏛️ Adaptação, Pontos de Apoio & Urbanismo
- Espaços urbanos desenhados para servir de abrigo climático e pontos de hidratação.
- Integração de soluções baseadas na natureza (SbN), fachadas verdes e estratégias passivas de conforto ambiental.
- Guia prático de emergência integrando contatos com **Bombeiros (193)**, **SAMU (192)**, **Defesa Civil (199)** e **Disque Saúde (136)**.

## 🎨 Design System & Identidade Visual

O projeto foi concebido sob uma direção de arte editorial que remete a cadernos de arquitetura e publicações científicas modernas:

| Elemento | Especificação / Conceito |
| :--- | :--- |
| **Paleta de Cores** | Tons terrosos, terracota quente (`#a74732`), carvão profundo (`#252522`) e areia mineral (`#f5f2eb`), simbolizando solo, calor e natureza. |
| **Tipografia Display** | `Archivo Black` e `Archivo` (pesos 700/800) para títulos de forte impacto visual e presença estrutural. |
| **Tipografia Editorial** | `Caveat` para anotações orgânicas e estilo manuscrito, contrastando com o rigor técnico. |
| **Tipografia Técnica** | `Space Grotesk` e `Space Mono` para metadados, números, estatísticas e indicadores analíticos. |
| **Tipografia de Leitura**| `Inter` garantindo legibilidade impecável para blocos de texto e artigos aprofundados. |
| **Composição** | Layout baseado em grid dinâmico, linhas de apoio, animações sutis de revelação (`Reveal`) e diagramas gráficos. |

## 🚀 Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- Gerenciador de pacotes `npm` ou `yarn`

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/RuanPablo2/clima-amanha.git
   cd clima-amanha
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no seu navegador:**
   Abra [http://localhost:5173](http://localhost:5173) para interagir com a aplicação.

5. **Gerar build de produção:**
   ```bash
   npm run build
   ```
